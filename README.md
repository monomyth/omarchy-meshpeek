# Model View (`local.modelview`)

Keyboard-first STL/3MF glance for Omarchy Quattro via [f3d](https://f3d.app).

## One shortcut

`Super + Shift + Ctrl + V` → `omarchy-shell local.modelview view`

1. **In Files** with a model highlighted → opens that file (no picker).
2. **Not in Files** → finds the newest model under Downloads/Prints/… and opens the file chooser in that folder so you can confirm (or pick another).

## Install

See bindings.snippet.lua. Needs f3d, wl-paste, jq, hyprctl.
